# 하이라이트 실제 실행 확인

호스트와 클라이언트는 같은 버전을 사용한다. 재생 전송 포맷은 v2이며 v1과 호환되지 않는다.
Unity 6000.3.22f1에서 EditMode 전체 테스트 후 두 인스턴스로 확인한다.

## 공통

- 재생 중 실제 KCC 캐릭터가 과거 위치로 순간이동하지 않는다.
- 1인칭에서 종료해도 리플레이 캐릭터의 몸이 보인다.
- 카메라, 물건, 캐릭터가 한 번에 초기화되고 페이드인 뒤에 사건이 진행된다.
- 게임 종료 후 3초 기록과 2초 전송 여유가 있으며, 늦은 수신자는 서버 시간에 맞춰 재생한다.
- 각 영상은 0.4초 준비, 0.3초 페이드인, 본편, 0.4초 종료 유지, 0.3초 페이드아웃, 0.2초 암전 순서다.
- 본편의 시간 점프에는 긴 암전이 없다. 영상 전체가 바뀔 때만 공통 전환을 사용한다.
- 결과 진입/씬 종료 시 원본 표시와 Cinemachine 제어가 복구된다.

## 종류별

- FIRST BLOOD: 최초 파괴 전 7초와 후 3초. 삭제된 물건이 과거에는 보이고 파괴 이후에는 사라진다.
- HOT ITEM(TTE TAN MULGUN): 초기 소지자를 포함해 서로 다른 사람이 같은 물건을 소지한다. 소지자 변경 전후의 최대 3구간, 합계 최대 10초. 같은 사람이 반복해서 집는 것은 새 이동으로 세지 않는다.
- FINAL MOMENT: 종료 직전 파괴/기절 또는 시간 만료 당시의 생존 물건. 첫 파괴와 동일한 사건은 반복 선정하지 않는다.
- LONGEST HIDDEN: 타인이 물건 4m 안에 접근한 경기가 필요하다. 접근 구간은 정상 속도, 빈 구간은 배속이며 근처에 사람이 없었던 물건은 해당 영상에서 제외한다.
- MOST STUNNED: 기절 전후 2초를 최대 3구간, 겹치는 시간은 반복하지 않는다. 기록된 타격/기절 동작이 재생된다.

5종을 모두 구현하지만 한 경기에는 우선순위대로 최대 3개만 나온다. LONGEST HIDDEN과 MOST STUNNED는 앞선 종류가 부족할 때 확인한다.

## 현재 검증 범위

- 게임 및 테스트 어셈블리의 C# 컴파일 확인.
- Unity와 독립된 전환 타이밍 계산 검사 통과.
- EditMode 실행은 작업 환경의 Unity 라이선스 오류로 미실행. 위 실제 화면 검증은 별도로 필요하다.
- 위치/회전, 물건 존재 여부, 확정 타격/기절을 기록한다. 점프/앉기/엎드리기와 공격이 빗나간 동작까지 완전 복원하는 애니메이션 녹화는 포함하지 않는다.
- 카메라 조연 선택은 가까운 플레이어 기준이며 최종 구도는 실제 맵에서 검증해야 한다.
