# Server

참가자 모두에게 영향을 주는 경기 규칙과 권한 판정을 순수 C#으로 구현합니다.

이 폴더의 Server는 별도 Spring 서버가 아니며 Photon Fusion 전송 계층도 아닙니다.
Fusion 연결, 방과 로비, 상태 복제는 `Network`가 담당합니다.

- 참가자 모두에게 영향을 주는 결과는 권한을 가진 영역에서 확정합니다.
- 경기 시간은 `Network`가 전달한 권한 시간 값을 기준으로 계산합니다.
- 확정된 결과는 `Network`가 참가자에게 복제합니다.
- Photon 타입을 참조하지 않아 EditMode 테스트에서 규칙을 독립적으로 검증할 수 있어야 합니다.
- `Client`를 직접 참조하지 않습니다.
