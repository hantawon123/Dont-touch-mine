# PoliceHoldingStylized — Empty Cell

Unity 6 / URP용입니다. Police_Holding_Stylized.prefab을 배치하세요.

- 철창 폭 약 7.17m 유지. 복도 폭도 약 7.17m로 맞춰 양옆 벽이 철창 끝에서 바로 이어집니다.
- 유치장 깊이를 6.85m에서 3m로 축소했습니다. 벽 두께를 제외한 내부 깊이는 약 2.63m입니다.
- 유치장 내부 침대·벤치·선반, 외부 보관함·시계·안내판과 양옆 돌출 벽을 제거했습니다.
- Detailed 버전의 재질, 색상, 벽돌 크기와 줄눈을 유지했습니다.
- 철창과 잠긴 문, 흰빛 출구를 유지했습니다. 출구 문은 복도 옆벽과 겹치지 않도록 나란히 열려 있습니다.
- 수정한 경계에 맞춘 BoxCollider 12개. 출구 통과 차단은 CharacterController로 검증했습니다.

Police_Holding_Demo.unity에서 16:9 구도를 확인하세요. 기존 씬의 카메라·조명은 자동으로 변경하지 않습니다.
제공 카메라: Position (0, 1.85, 7.6), Rotation (4.514, 180, 0), FOV 40.426.
