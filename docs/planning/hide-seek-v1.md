# 숨기기–찾기 대결 학습 v1 설계서

상태: 초안(2026-09-25). H1~H9 확인 후 구현.

## 1. 목적

"좋은 숨길 자리"를 공식(숨김 점수)으로 정하지 않고, **플레이어처럼 보고 움직이는 수색자가 실제로 늦게 찾은 자리**로 배우게 한다. 숨김 점수 v3와 은행은 보기(놓을 수 있는 자리 목록)와 비교 기준으로만 쓴다.

NPC에 들어갈 것은 **숨기는 두뇌**다. 찾는 두뇌는 학습 상대이자, 나중에 NPC가 사람 물건을 찾아 다시 숨기는 역할로 확장할 수 있다.

## 2. 두뇌를 둘로 나누는 이유(H1)

| | 두뇌 하나(역할 교대) | 두뇌 둘(비대칭 대결) |
| --- | --- | --- |
| 판단의 모양 | 숨기기(한 판에 1~2번 고르기)와 찾기(수십 번 이어지는 판단)를 한 신경망이 같이 배움 | 각자 자기 판단만 배움 |
| 관측·행동 | 두 역할을 한 벡터에 넣고 마스크로 가림 | 역할에 맞게 설계 |
| 보상 추적 | 역할마다 보상 시점이 달라 섞임 | 깔끔함 |
| 평가 | 역할별 분리가 어려움 | 숨기기·찾기를 각각 기준선과 비교 가능 |
| ML-Agents | 대칭 셀프플레이 | 비대칭 셀프플레이(두 팀, 두 행동 이름) |

숨기기는 결정 수가 적고 찾기는 길어서, 한 신경망에 섞으면 숨기기 쪽 학습이 느리다. **두뇌 둘**로 간다. "주우면 숨기는 쪽이 된다"는 연쇄는 v2에서 같은 몸에 두 두뇌를 번갈아 붙이는 방식으로 확장한다.

## 3. 학습장(가벼운 시뮬레이터)

Fusion·KCC 없이, 저택 샌드박스 씬(반경 0.35 m NavMesh, 소품 824개)을 그대로 쓴다.

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 몸 | 반경 0.31 m, 키 1.67 m | NetworkedPlayer(9/23) |
| 이동 | NavMesh 경로 모퉁이를 따라 걷기 3.5 m/s, 앉아 걷기 1.5 m/s, 회전 720°/s. **달리기 없음**(H7 사용자 결정). 점프는 게임에선 가능하나 NavMesh 걷기에 필요 없어 1단계 미구현 | MovementConfig |
| 눈높이 | 서기 1.42 m, 앉기 0.85 m, 엎드리기 0.46 m | MovementConfig |
| 제자리 둘러보기 | 초당 180°(한 바퀴 2초), 앉아 둘러보기는 0.75배 | 설정값 없음, 사람이 훑는 속도로 가정 |
| 시야 | 1인칭 눈 위치, 세로 60° × 가로 약 91°(16:9), 거리 20 m | PlayerCameraRig FieldOfView 60 |
| 가림 | 모든 콜라이더(벽·가구·**소품 포함**) | 플레이어가 보는 그대로 |
| 물건이 보임 | 물건 상자 표본점 10개 중 3개 이상이 시야 원뿔 안에서 가림 없이 보이고, 화면상 크기(각지름) 1° 이상 | 벽 너머·점 하나 보이기 금지 |
| 상대가 보임 | 상대 몸의 머리·가슴·골반 3점 중 1점 이상이 같은 규칙으로 보임 | |
| 찾음 | 수색자가 물건에서 2 m 안(잡기 거리), 물건이 보이는 상태에서 줍기 | InteractionAuthorityRules 2 m, 사용자 결정 |
| 숨김(놓기) | 숨기는 쪽이 고른 은행 자리의 선 자리까지 걸어가 놓음. 놓기 직전 실제 배치 규칙(겹침·받침면, 소품 포함)으로 다시 검사 | 은행 D3 한계 보완 |
| 속도 | 시간 20배속, 한 씬에 8판 동시(판끼리 서로 보이지 않음) | Fusion이 없으므로 배속이 실제로 먹힘 |

한 판:

1. 숨기는 쪽이 물건을 든 채 무작위 위치에서, 수색자는 다른 무작위 위치에서 시작(직선 8 m 이상).
2. 둘이 **동시에** 움직인다. 숨기는 쪽은 **20초 안에** 놓아야 한다(넘기면 발밑에 떨어짐).
3. 놓은 뒤 숨기는 쪽은 코드로 먼 곳으로 걸어간다(그 자리에 서서 위치를 알려 주지 않게).
4. 수색자가 물건을 주우면 끝. 150초가 지나도 못 찾으면 끝.

## 4. 숨기는 두뇌

- **결정 시점:** 판 시작, 이동이 끝날 때마다(20초 안).
- **행동(9개):** 은행 후보 8곳 중 하나로 가서 놓기, 또는 "다른 곳으로 이동"(탐색 지점 하나로 걸어가 새 후보 받기 — "아예 다른 곳"으로 옮길 수단).
- **후보 8곳:** 현재 위치에서 경로 15 m 안, 물건 크기가 들어가는 은행 자리 중 무작위.
- **관측(자기):** 남은 제한 시간, 자세, 스태미나.
- **관측(후보마다):** 방향·경로 거리, 받침면 높이, 태그(밑·가구 위·구석), v2.1과 같은 시선 광선 요약(자리에서 눈높이 방향으로 막힌 정도). **은행 숨김 점수는 넣지 않는다**(H6, 정답 누설 방지).
- **관측(상대):** 마지막으로 본 상대 위치(상대 방향·거리)와 경과 시간, 지금 보이는지, 마지막으로 본 상대 위치에서 각 후보가 보이는지.
- **보상:** 판 끝에 2 × 숨겨진 비율 − 1(숨겨진 비율 = 발견 시각 / 150초, 못 찾으면 1). −1~1, 제로섬(셀프플레이 ELO가 부호로 승패 판단). 제한 시간 초과 −0.5 추가.

## 5. 찾는 두뇌

- **결정 시점:** 이전 행동이 끝날 때마다(보통 1~5초).
- **행동(12개):** 탐색 후보 8곳 중 하나로 이동 / 제자리 한 바퀴 / 앉아서 한 바퀴(낮은 곳 보기) / 본 물건으로 가서 줍기 / 본 상대 쫓기. 가능하지 않은 행동은 마스크.
- **탐색 후보 8곳:** 걸어서 탐색(Explore v2) 지점 중 가까운 미방문 우선.
- **관측(후보마다):** 방향·경로 거리, 마지막 방문 뒤 경과 시간, 주변 은행 자리 수(태그별 — 지형 정보, 점수 아님).
- **관측(기타):** 경과 시간, 스태미나, 물건을 본 적 있는지와 마지막 위치, 상대를 본 적 있는지와 마지막 위치·그때 물건을 들고 있었는지.
- **보상:** 숨기는 쪽 보상의 부호 반대(−(2 × 숨겨진 비율 − 1)). 빨리 찾을수록 +1에 가까움.

두 보상은 거의 대칭(한쪽이 얻으면 다른 쪽이 잃음)이다.

## 6. 학습 설정

- ML-Agents 비대칭 셀프플레이: 행동 이름 `HideSelect`(team 0), `SeekSelect`(team 1).
- 각자 과거 자기 모델(유령)들과 번갈아 붙음. ELO 곡선 기록.
- 설정 파일은 ASCII만(cp949 문제).
- 학습 중 Assets 편집 금지.

## 7. 평가(고정 시드, 판당 같은 시작 배치)

| 숨기기 \ 찾기 | 무작위 수색 | 규칙 수색(가까운 미방문 지점 + 한 바퀴 + 가구 근처에선 앉아 보기) | 학습 수색 |
| --- | --- | --- | --- |
| 무작위(후보 8곳 중) | | | |
| 규칙(은행 숨김 점수 최고) | | | |
| 학습 | | | |

칸마다 200판: 발견율, 평균 발견 시각.

성공 기준:
- 학습 숨기기가 규칙 숨기기보다, 규칙 수색·학습 수색 **둘 다**를 상대로 더 늦게 발견된다.
- 학습 수색이 규칙 수색보다, 규칙 숨기기를 상대로 더 빨리 찾는다.
- 한쪽만 이기면(서툰 상대 공략) 성공이 아니다.

이후: 학습 숨기기를 실제 봇 몸(저택 샌드박스)으로 옮겨 규칙 수색 상대로 재확인, 사람 플레이테스트.

## 8. 구현 순서

1. 시뮬레이터: 몸·이동·시야·판 진행·8판 동시·디버그 표시.
2. 규칙 두뇌 3종씩 + 평가 도구 + 기준선 결과표.
3. ML-Agents 두뇌 2개, 관측·행동·보상, 셀프플레이 설정, 짧은 시험 학습.
4. 밤새 본 학습 → 평가.

### 10.2 초기 오류와 수정

- 수색자가 물건을 본 비율 61~77%인데 발견 3~16%: 다가갈 때 시선이 수평이라 가까이 가면 물건이 시야각 아래로 빠짐(10.1의 "1 m 앞 바닥" 항목과 같은 현상). **다가가는 동안 시선이 물건을 따라가게** 수정(플레이어가 카메라를 목표로 돌리는 것과 같음), 물건 근처 NavMesh 찾기 반경 1.5 → 3 m. 규칙 수색은 도착 후 못 찾으면 앉아서 둘러봄.
- 빌더가 은행을 씬 전환 전에 불러와 참조가 비는 문제, NavMeshPath 필드 초기화 오류 수정.

- **학습 숨기기: 아직 규칙 숨기기에 못 미침.** 무작위보다는 나음(규칙 수색 상대 0.503 → 0.613, 무작위 수색 상대 0.629 → 0.730). 규칙 숨기기와의 차이(−0.027, −0.028)는 200판 표준오차(약 0.025) 수준. 학습 수색 상대로도 규칙 숨기기(0.589)가 학습 숨기기(0.527)보다 높음.
- 학습 숨기기는 들고 있는 모습을 들킨 비율이 30~33%(규칙 숨기기 15~25%)이고 늦은 떨굼 1~2건. 다른 곳으로 옮기기를 더 쓰는 것으로 추정(미확인).
- 판정: 성공 기준(7절) 미달. 숨기기 학습 4만 결정은 목표 25만의 16%라 계속 학습 후 재평가.
