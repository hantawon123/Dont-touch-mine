# 매치 맵 "마트" — Jira 태스크 초안 (2026-09-10)

메인(매치) 맵을 마트 테마의 로우폴리 에셋으로 새로 제작하기 위한 태스크 분해.
로비 지하실 에픽(609: 611~618)의 단계 구조를 따르되, 매치 맵에만 있는 요소(숨김 장소, 파쇄기, 탈출 지점, 맵 등록)를 추가했다.
이슈 번호: 에픽 901, 태스크 902~915 (2026-09-10 발급). 괄호 안 숫자가 S15P21D205-### 번호. 커밋은 `S15P21D205-### [CL] 태그: 제목`.

전제
- 규칙: 6인, 숨기기 3분 + 본게임 6분, 각자 물건 1개 숨김, 파쇄기(인당 5회), FINAL 30초에 경찰 도착·탈출 지점 이동.
- 현재 매치 씬은 `Playground.unity` 하나이고 `MapCatalog`에 `playground` id만 있다. 맵 씬은 `NetworkScenes.asset`의 MatchScene(빌드 인덱스)으로 로드된다.
- 스타일 기준: LowPolyInterior2와 같은 팔레트 로우폴리. 로비는 필요 시 변환기(`LobbyLowPolyTestMenu`)로 톤을 맞춘다.
- 에셋 라이선스: Restricted(UGC 플랫폼 수익화·NFT 금지) — 우리 게임은 해당 없음. 원본 .unitypackage는 저장소에 넣지 않는다.
