# [와이어] 캐릭터 옷장 페이지 구현

- 담당: 김채린

외형 고르기 화면. 버튼 동작은 환경설정과 같다.

## 화면 배치

- [ ] 한쪽에 캐릭터 미리보기가 있다
- [ ] 다른 쪽에 종류 / 색상 / 얼굴 표정 / 헤어 / 기타 선택 영역이 있다
- [ ] 하단(또는 고정 영역)에 초기화 / 적용 / 이전이 있다

## 동작

- [ ] 파츠를 고르면 미리보기가 바로 바뀐다
- [ ] 바꾸기 전에는 초기화·적용이 꺼져 있다
- [ ] 바꾸면 초기화·적용이 켜진다
- [ ] 적용하지 않고 나가려 하면 저장 확인 모달이 뜬다
- [ ] 이전을 누르면 들어온 화면으로 돌아간다

## 유스케이스

- [ ] 외형을 고르고 미리본 뒤 적용한다
- [ ] 적용 전 선택을 초기화한다
- [ ] 저장하지 않고 나가려다 확인 모달에서 남거나 버린다
