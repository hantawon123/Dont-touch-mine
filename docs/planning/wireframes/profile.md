# [와이어] 프로필 설정 모달창 구현

- 이슈: [S15P21D205-450](https://ssafy.atlassian.net/browse/S15P21D205-450)
- 담당: 양혜림

닉네임과 검색 허용을 바꾸는 모달.

## 화면 배치

- [ ] 화면 중앙에 모달이 있고, 뒤 Home은 가려지거나 딤 처리된다
- [ ] 현재 닉네임이 보인다
- [ ] 닉네임 입력칸과 중복 체크 버튼이 있다
- [ ] `닉네임 검색 허용` 토글이 있다
- [ ] 적용 / 닫기가 있다

## 동작

- [ ] 한글/영문/숫자만, 2~12자. 공백·특수문자는 입력되지 않거나 오류가 난다
- [ ] 규칙에 맞지 않으면 오류 문구가 입력칸 근처에 뜬다
- [ ] 중복 체크를 통과하기 전에는 적용이 꺼져 있다
- [ ] 중복이면 적용이 꺼진 채 안내가 뜬다
- [ ] 통과하면 적용이 켜진다
- [ ] 적용 성공 시 피드백이 보인다
- [ ] 닫으면 Home이 다시 보인다

## 유스케이스

- [ ] 닉네임을 규칙에 맞게 바꾸고 중복 확인 후 적용한다
- [ ] 잘못된 닉네임·중복 닉네임은 적용하지 못한다
- [ ] 닉네임 검색 허용을 켜거나 끈다
