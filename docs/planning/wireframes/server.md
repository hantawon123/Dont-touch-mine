# [와이어] 서버 설정 모달창 구현

- 이슈: [S15P21D205-452](https://ssafy.atlassian.net/browse/S15P21D205-452)
- 담당: 김채린

리전을 고르는 모달.

## 화면 배치

- [ ] 화면 중앙에 모달이 있고, 뒤 Home은 가려지거나 딤 처리된다
- [ ] 아시아 / 북미 / 오세아니아 / 유럽이 선택 목록으로 보인다
- [ ] 지금 고른 리전이 강조된다
- [ ] 적용(또는 선택 확정) / 닫기가 있다

## 동작

- [ ] 리전을 누르면 선택 표시가 그쪽으로 옮겨간다
- [ ] 확정하면 모달이 닫히거나 선택 상태가 유지된 채 닫힌다
- [ ] 다시 열면 마지막에 고른 리전이 강조되어 있다
- [ ] 닫으면 Home이 다시 보인다

## 유스케이스

- [ ] 리전을 고르고 확정한다
- [ ] 나중에 다시 열어 현재 리전을 확인하거나 바꾼다
