# [와이어] 친구 목록(추가) 모달창 구현

- 이슈: [S15P21D205-449](https://ssafy.atlassian.net/browse/S15P21D205-449)
- 담당: 양혜림

Home 위에 뜨는 친구 모달. 목록 보기와 친구 추가가 탭으로 갈린다.

## 화면 배치

- [ ] 화면 중앙에 모달이 있고, 뒤 Home은 가려지거나 딤 처리된다
- [ ] 상단에 `친구 목록` / `친구 추가` 탭이 있다
- [ ] 목록 탭: 새로고침, 닉네임 검색창, 친구 행(닉네임·상태)
- [ ] 추가 탭: 받은 요청 목록(수락/거절), 닉네임 검색창, 요청 보내기
- [ ] 닫기(X 또는 바깥 클릭)가 있다

## 동작

- [ ] 탭을 바꾸면 해당 목록만 보인다
- [ ] 목록 탭에서 검색하면 보이는 친구가 걸러진다
- [ ] 목록은 온라인 → 오프라인(스팀 온라인) → 오프라인(스팀 오프라인) 순이다
- [ ] 새로고침을 누르면 목록이 다시 그려진다
- [ ] 추가 탭에서 닉네임을 검색하고 요청을 보낸다
- [ ] 받은 요청에서 수락/거절을 누르면 해당 행이 갱신된다
- [ ] 닫으면 Home이 다시 보인다

## 유스케이스

- [ ] 친구 상태를 보고 검색한다
- [ ] 받은 요청을 수락하거나 거절한다
- [ ] 닉네임으로 친구를 찾아 요청을 보낸다
