# 🎮 게임 기획 요약 & 체크리스트

> 페이지별 내용 요약과 미정/확인 필요 사항을 정리한 문서입니다.

---

## 📌 게임 개요 (파악되는 범위)

- 멀티플레이 파티 게임, 방(룸) 기반 매칭
- 콘셉트: **숨기기(도둑) vs 찾기(경찰)** 형태의 술래잡기류
  - 참가자는 특정 물건을 배정받아 숨기고, 시간 내 지켜내면 탈출 성공
  - 제한 시간 내 물건이 파괴되면 실패(검거)
- 1인칭/3인칭 시점 전환 지원
- 방장이 방/맵/규칙을 세부 설정 가능

## 🖥️ 페이지별 요약

### 1. 메인 페이지
방 만들기 / 게임 찾기 / 게임 종료 / 환경설정 / 캐릭터 옷장 / 친구 목록 / 프로필 설정 / 서버 설정으로 진입하는 허브 화면.

### 2. 환경 설정 페이지
일반 / 그래픽 / 인터페이스 / 사운드(오디오) / 컨트롤(조작) / 알림 총 6개 탭 구성.
공통 규칙: 변경사항 없으면 초기화·적용 버튼 비활성화, 변경 후 이탈 시 저장 여부 확인 모달.

**세부 항목**
- 그래픽: 디스플레이 모드, 해상도, FPS 제한, 안티앨리어싱, HBAO, 텍스처/그림자 품질, 피사계 심도, 볼륨
- 인터페이스: UI/글자 크기, 게임 내 UI, FPS·핑 표시, 플레이어 이름/닉네임 공개 범위, 채팅 범위 제한 등
- 사운드: 마스터/배경음/환경음/효과음 볼륨, 마이크 장치·입력모드·볼륨·테스트
- 컨트롤: 1인칭/3인칭 각각 마우스 감도, 카메라 감도, X/Y축 반전
- 알림: 게임중/친구요청/게임초대 알림 on-off

---

### 3. 캐릭터 옷장 페이지
캐릭터 종류 / 색상 / 얼굴 표정 / 헤어 / 기타 커스터마이징. 초기화·적용·이전 버튼 규칙은 환경설정과 동일.

---

### 4. 친구 목록(추가) 모달창
- **친구 목록 탭**: 새로고침, 닉네임 검색, 온라인 → 오프라인(스팀 온라인 우선) → 오프라인(스팀 오프라인) 순 정렬
- **친구 추가 탭**: 받은 요청 목록(수락/거절), 정확한 닉네임 검색 후 요청 전송

---

### 5. 프로필 설정 모달창
- **닉네임 변경**: UTF-8, 한/영(대소문자 구분)/숫자만, 공백·특수문자 불가, 2~12자
- 중복 체크 필수 → 통과해야 적용 버튼 활성화
- **닉네임 검색 허용** 토글

---

### 6. 서버 설정 모달창
아시아 / 북미 / 오세아니아 / 유럽

### ❓ 확인 필요
- [ ] 서버 목록이 이 4개로 확정인지, 세부 리전(예: 아시아 내 한국/일본 등) 분리 필요한지 확인

---

### 7. 게임 찾기 페이지
- 방 제목 검색, 방 목록(최신순 → 동시간이면 방 이름순)
- 방 아이템: 방 이름 / 맵 / 인원 / 방장 닉네임 / 게임중 여부 (게임중이면 입장 불가)
- 방 코드 입력 입장: 영대문자+숫자 6자리, 소문자 입력 시 자동 대문자 변환

---

### 8. 방 만들기 모달창
- Public/Private, 방 제목(UTF-8, 1~20자, 공백/중복 허용)
- 최대 인원 (MVP 기준 6명)
- 방 제목 미입력 시 생성 버튼 비활성화

---

### 9. 로비 씬
- 환경설정 / 캐릭터 설정: 로비에서 변경한 캐릭터는 게임 종료 후에도 유지
- 게임 나가기: 방장 이탈 시 방 폭파(경고 모달), 일반 유저는 바로 이동
- 참여자 목록: 방장 표시(왕관), 마이크 상태, 강퇴(방장 전용)
- 게임 초대: 인원 꽉 찼을 시 버튼 숨김
- 채팅: 엔터로 활성화/전송/비활성화
- **방 설정(방장 전용)**: 방 제목, 방 코드 복사, 인원(2~6), 파괴 가능 횟수(무한 옵션), 숨는 시간(10~120초, 기본 30초), 찾는 시간(1~15분, 기본 5분), 달리기 속도(0.5~3배), 기절 펀치 횟수/HP(기본 3회)
- **맵/카테고리 설정(방장 전용)**: 맵 선택, 물건 카테고리(랜덤/과일/기타)
- 게임 시작: 10초 카운트다운 후 입장

---

### 10. 인게임 - 숨기기 단계
- 배정 물건 안내 텍스트(일정 시간 후 사라짐)
- 캐릭터 위 채팅 텍스트 표시
- 대기자: 숨기기 순서 안내(N/6명), 이동 가능
- 숨기는 사람: 남은 시간, 시간 초과 시 마지막 위치에 자동 배치, 완료 버튼

---

### 11. 인게임 - 진행 단계
- 채팅(캐릭터 위 텍스트)
- 카테고리 + 배정 물건 (남은/파괴된 물건) — 추후 탭 UI로 변경 가능성 있음
- 전체 남은 시간, 스테미나/체력 바, 키 세팅 가이드

---

### 12. 인게임 - Final 30초
- "경찰 도착 임박" 경고 문구
- 남은 시간 강조 색상 변경
- 나머지 UI는 진행 단계와 동일 구성

---

### 13. 인게임 - 엔딩
- 물건 보유 시 탈출 성공 / 분실 시 검거 문구
- 5초 노출, 디자인에 따라 상호작용 연출 가능성

---

### 14. 인게임 - 하이라이트
