# 도둑 NPC v2 설계서 — 지금 게임에 NPC만 추가

상태: 초안(2026-09-26). V1~V9 확인 후 구현.

## 1. 확정된 방향(사용자)

- NPC 역할은 **물건 도둑**: 플레이어가 숨긴 물건을 찾아 다른 곳에 다시 숨긴다.
- 플레이어가 NPC를 기절시키면 **플레이어와 똑같이** 들고 있던 물건을 떨어뜨린다.
- NPC는 **게임이 끝날 때까지 계속 움직인다**(v1처럼 숨긴 뒤 서 있지 않음).
- 플레이어는 **지금 게임에서 할 수 있는 모든 행동을 그대로** 한다. NPC만 추가된다.
- NPC는 달리지 않는다(v1 결정 유지). 점프는 가능하나 NavMesh 걷기에는 필요 없음.

## 3. 학습장 v2(가벼운 시뮬레이터 확장)

v1 시뮬레이터(시야, 몸, 은행, 접근 규칙)를 그대로 쓰고 다음을 더한다.

- **참가자:** 플레이어 봇 N명 + 도둑 NPC 1명. 물건은 플레이어마다 1개.
- **판 시작 = 수색 시작:** 숨기기 단계는 시뮬레이션하지 않고, 플레이어 물건이 이미 숨겨진 상태로 시작(NPC는 수색 단계에 투입되므로). 숨긴 자리는 플레이어 숨기기 방식(V4)으로 정함.
- **알아보기:** 플레이어는 **자기 물건만** 알아봄(외곽선). 남의 물건은 일반 소품과 구별 못 함. 다만 누가 무엇을 들고 있으면 그 사람이 뭔가 들고 있다는 것은 보임.
- **전투:** 게임 규칙 그대로(3타 기절 2초, 떨굼). 떨어진 물건은 누구나 주울 수 있음.
- **판 끝:** 360초. 자기 물건을 든 플레이어 수로 결과를 셈.

## 4. 도둑 NPC

- **행동(큰 판단만, 걷기·보기·줍기는 코드):**
  - 수색: 탐색 후보 8곳 중 이동 / 둘러보기 / 앉아 둘러보기
  - 본 플레이어 물건으로 가서 줍기
  - 들고 있을 때: 은행 후보 8곳 중 숨기기 / 다른 곳으로 옮기기
  - 플레이어가 다가올 때: 도망 / 공격(V6)
- **관측:** v1 두 두뇌의 관측을 합치고, 플레이어는 가까운 순 3명의 슬롯(보이는지, 마지막 위치, 무엇을 들었는지, 나를 쫓는지)으로 넣음. 은행 숨김 점수는 넣지 않음(정답 누설 금지 유지).
- **알아보기(V2):** NPC는 플레이어 물건을 **보면** 알아봄. 어디 있는지는 모름(찾아야 함).
- **보상(V7):** 판 끝에 −(자기 물건을 든 플레이어 수 / N). 중간 보상은 V7에서 결정.

## 5. 플레이어 봇(V3, V4, V5)

사람 플레이어를 대신하는 상대. 권장은 **규칙 봇**(사람이 할 법한 행동을 코드로):

- 자기 물건이 어디 있는지 기억(자기가 숨겼으므로). 수색 시작 후 일정 시간 안에 가서 확인 또는 들기.
- 자기 물건을 들고 있으면: 끝날 때까지 들고 버티기, 다가오는 상대를 피하거나 반격.
- 자기 물건이 없어졌으면(NPC가 옮김): v1 찾는 쪽처럼 수색. 자기 물건을 든 누군가를 보면 쫓아가 공격.
- 남의 물건: 알아볼 수 없으므로 목표로 삼지 않음. 파쇄기는 v2a에서 제외(V8).
- 실력 차이를 흉내 내기 위해 판마다 반응 속도·기억 시간·공격성을 무작위로(과적합 방지).

## 6. 학습 방식

- 도둑 NPC만 학습, 플레이어는 규칙 봇(V3). 셀프플레이 교대가 없어 v1보다 빠르고 안정적.
- 평가: 도둑 없음 / 무작위 도둑 / 규칙 도둑 / 학습 도둑 × 같은 판 배치 200판 × 2 시드. 지표는 **자기 물건을 든 채 끝낸 플레이어 비율**(도둑이 낮출수록 잘함), 도둑이 물건을 옮긴 횟수, 도둑이 기절한 횟수.
- 성공 기준: 학습 도둑이 규칙 도둑보다 두 시드 모두에서 승리 플레이어 비율을 더 낮춤.
- 관전 화면 확장: 플레이어 N명 + 도둑.

### 9.1 줍기 규칙을 게임과 맞춤(HideSeekReach, v1·v2 공용)

- 발견된 허점: 놓기 2.8 m / 줍기 2 m 차이로 "놓을 수는 있지만 주울 수 없는 자리"가 은행에 약 8%. 도둑 없는 기준선에서 플레이어 15.5%가 자기 물건을 못 듦.
- 원인 분해(500곳): 대부분 시뮬레이터 한계 — 높은 물건 아래 바닥을 못 찾던 탐색(64), 점프 없음. 게임 규칙상 정말 못 줍는 곳은 일부.
- 수정: 줍기 = 발에서 물건까지 3D 2 m(PlayerInteractor / InteractionAuthorityRules와 같음), **점프 줍기**(발·눈 +0.85 m), **1.1 m 이하 가구 위로 올라가 줍기**, 서기·앉기·엎드리기·점프 눈높이에서 보여야 함. 줍기 가능 자리: 가구 밑 99%, 가구 위 98%(점프 39, 올라가기 3 / 250), 구석 98%, 빈 바닥 94%. 그래도 못 줍는 자리는 숨길 후보에서 제외(NPC가 물건을 영영 못 찾게 만드는 행동 방지).
- 이 수정 전의 v1.1 학습(hs-v11-b3-seed101)은 허점을 이용할 수 있어 중단·폐기.
