# 캐릭터 모델링 (Modeling)

메인 캐릭터 3D 모델링 작업 과정과 중간 결과 이미지를 둡니다.

- 파일명은 영문 소문자와 하이픈, 단계/버전 표기. 예: `body-resize-v1.png`
- 작업 단계별 스크린샷과 설명을 이 폴더에 쌓고, 과정 정리는 md 문서로 남깁니다.

## 작업 흐름 (예정)

1. 베이스 에셋 리서치·구매
2. 블렌더에서 몸통 해체·파츠 정리
3. 비율 조정 (팔·다리·몸통)
4. 눈 모델링·부착
5. 질감·색감 조정 (6색 프리셋)
