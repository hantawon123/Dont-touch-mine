# 스타일 가이드

게임 전체의 시각 톤을 맞추기 위한 기준입니다. 확정되지 않은 항목은 `(안)`으로 표시하고, 결정되면 갱신합니다.

## 톤앤매너

- 아트 스타일: **로우폴리(Low Poly)** — 인게임 맵·소품·캐릭터 공통
- 감성: 아기자기한 난장판 파티게임. 무섭거나 진지하지 않게, 장난감 상자 느낌
- 레퍼런스: 파티애니멀즈(감성), 리썰컴퍼니(1인칭 조작감), 폴가이즈(캐릭터 실루엣)

## 캐릭터 (안)

- 캡슐형 몸통 + 왕눈이 — 자체 시안 기준
- 시안 배색: 검은색 몸통/ 노란 신발
- 6인 구분: 몸통 색으로 플레이어 구분 (팔레트 아래 표 참고)

## 폰트

- 한글: Paperlogy (프로젝트에 적용됨)
- 용도별 크기·굵기 규칙: 미정

## 씬별 무드 (안)

- 홈/방 찾기: 미정
- 대기실(로비): 창고 — 지하실 (아지트) 기반
- 인게임 맵: 2층 주택 — Low Poly House Interior & Exterior 기반
- 결과 화면: 경찰서 컨셉 (기획서 참고)

## UI 원칙 (안)

- HUD는 화면 가장자리, 중앙은 크로스헤어만
- 전체 공지(파괴 알림 등)는 상단 배너
- 자세한 화면별 시안은 `ui/` 폴더 참고
