소스에는 SerializeCompressed의 원본 byte[] 생성과 output.ToArray, TryDeserializeCompressed의 입력 ToArray·압축 해제 output.ToArray, 프레임 생성 시 배열 복사가 있다. 이들은 이후 개선 후보이며 각 복사가 차지하는 비용을 이번 전체 호출 측정만으로 분리·확정할 수 없다. 기존 GZip이나 revision 변경 감지를 다시 구현하지 않는다. 입력 크기·유효성 검사는 유지한다.
