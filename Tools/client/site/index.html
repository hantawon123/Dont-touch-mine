설치 및 실행 방법

  1. 01

    최신 베타 버전을 다운로드하세요.

    다운로드 버튼으로 Windows용 ZIP 파일을 받으세요. 함께 플레이할 친구들도 최신 버전을 사용해야 합니다.

  2. 02

    ZIP 파일의 압축을 모두 풀어주세요.

    파일을 오른쪽 클릭한 뒤 ‘모두 압축 풀기’를 선택하세요. 실행 파일과 데이터 폴더를 같은 위치에 유지하세요.

  3. 03

    Game.exe를 실행하고 방에 참가하세요.

    인터넷에 연결한 상태에서 실행하세요. 한 사람이 방을 만들고, 나머지 플레이어가 해당 방에 참가하면 됩니다.

플레이 전 확인해주세요

브라우저에서 바로 플레이할 수 있나요?

현재는 Windows 클라이언트로 제공됩니다. ZIP 파일을 내려받아 압축을 푼 뒤 실행해 주세요.

친구의 방이 보이지 않아요.

친구와 같은 게임 버전과 지역을 사용하는지 확인하세요. 업데이트 후에는 모두 최신 ZIP을 받아 다시 실행해 주세요. 서버가 다음 방을 준비하는 동안에는 잠시 기다렸다가 다시 시도해 주세요.

새 버전으로 자동 업데이트되나요?

현재는 수동 다운로드 방식입니다. 최신 ZIP을 새로운 폴더에 압축 해제한 뒤 실행하세요. 실행 중인 게임 파일 위에 덮어쓰지 마세요.

실행되지 않거나 문제가 생겼어요.

ZIP 내부에서 바로 실행하지 않았는지, Game.exe와 Game_Data 폴더가 함께 있는지 확인하세요. 문제가 계속되면 참여 안내를 받은 채널로 발생 시각, 화면, 아래 다운로드 버전을 전달해 주세요.
